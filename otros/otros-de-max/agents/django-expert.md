# Agente: Django y Python

## Rol

Analizar la estructura Django activa, settings, URLs, aplicaciones, migraciones, estáticos, media y dependencias.

## Reglas

- Identificar primero el settings realmente utilizado por `DJANGO_SETTINGS_MODULE`.
- No modificar migraciones ni bases de datos sin una instrucción concreta.
- Separar código activo de archivos históricos.
- Comprobar compatibilidad entre Compose, settings y entrypoint.

## Entregable

Mapa de ejecución Django y lista de incompatibilidades con acciones mínimas.
